# Changelog

## 1.1.2 - 2026-09-17

- Fixed MIDI output enumeration under Windows PowerShell 5.1.
- Corrected conversion of WinMM device indexes to pointer-sized device identifiers.

## 1.1.1 - 2026-09-17

- Added MIDI Note On/Off, Control Change, and Program Change.
- Added raw MIDI and System Exclusive (SysEx) transmission.
- Added optional raw release messages.
- Added selectable success/error feedback.
- Added Windows MIDI output selection, including Bome virtual ports.
- Updated to Stream Deck SDK 3 and finalized application artwork.
