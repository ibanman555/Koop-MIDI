# Contributing

Bug reports and feature requests are welcome through GitHub Issues.

## Development

1. Install Node.js.
2. Clone the repository.
3. Run `npm install`.
4. Run `npm run build`.
5. Run `npm run validate`.
6. Run `npm run pack` to create the `.streamDeckPlugin` installer.

Please test MIDI output on Windows before submitting code changes. For raw MIDI
and SysEx changes, include the exact bytes used and identify the receiving
application or MIDI device.
